# Conta Bancária em Java

Este projeto foi desenvolvido em Java com o objetivo de praticar conceitos fundamentais da linguagem e lógica de programação.

A aplicação simula uma conta bancária através do terminal, permitindo:

* Consultar saldo
* Receber valores
* Transferir valores
* Encerrar a aplicação

Durante o desenvolvimento foram utilizados conceitos como variáveis, estruturas condicionais (`if` e `else`), laços de repetição (`while`) e entrada de dados com a classe `Scanner`.

Projeto desenvolvido como prática de Java e lógica de programação.
